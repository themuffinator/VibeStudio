Before you install VibeStudio

VibeStudio is pre-alpha software. Most features have automated tests, but very
little has been tried in real projects yet, and this installer is new.

- Work on copies of your maps, packages and projects, and keep backups.
- VibeStudio never changes a game installation unless you ask it to deploy a
  test map, and it asks before it does.
- Your settings stay in your user profile; uninstalling leaves them in place.

The documentation installed alongside the studio (Start menu > VibeStudio
Documentation) explains what works today and how to report a problem:
https://github.com/themuffinator/VibeStudio/issues
