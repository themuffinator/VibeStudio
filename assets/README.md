# Assets

Shared artwork for the studio and its releases.

- `branding/`: the VibeStudio logo, wordmark, banners, social preview, app
  icons for every platform, installer art and documentation favicons, all
  generated by `scripts/generate_branding.py`. Rules and the file index are in
  [docs/BRANDING.md](../docs/BRANDING.md).

Borrowed or adapted artwork must be added to `docs/CREDITS.md` and the README
Credits section with an upstream link, license, and revision or release tag.
Never add assets from commercial games.
