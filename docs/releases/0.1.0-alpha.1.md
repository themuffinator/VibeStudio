# VibeStudio 0.1.0-alpha.1

## Highlights

The first public preview of VibeStudio, an all-in-one development studio for
idTech 1, 2 and 3 games. It is an early look, published so people can try it and
tell us what breaks, not a tool to trust with a production project yet.

- **One studio for the whole loop.** Levels, models, textures, audio,
  packages, code, compilers and game launching share one window, one project
  and one command line.
- **Levels.** Open, edit and save Doom-family maps (including UDMF properties)
  and Quake, Quake II and Quake III `.map` files in 2D and 3D views, with undo,
  entity validation and a backup copy every time you save.
- **Familiar controls.** Editor profiles bring the keys, mouse gestures and
  camera of TrenchBroom, NetRadiant Custom, GtkRadiant, QuArK and other
  editors.
- **Packages.** Browse, extract, validate and compare PAK, PK3/ZIP and WAD
  files, and stage changes into a new package.
- **Assets.** Decode idTech textures with their palettes, edit models and
  sounds, and export to each game's formats.
- **Build and launch.** Run VibeMap2, VibeMap3, ZDBSP and ZokumBSP pipelines
  with a Problems list and leak trails, then launch the game with your map.
- **Command line.** 234 scriptable commands with JSON output share the studio's
  services.
- **Optional AI.** Off by default. Opt in to ask a model about your work, with
  a preview of every request before it is sent.
- **Installers and documentation.** A Windows installer and portable ZIP, a
  macOS disk image, a Linux AppImage, and the user manual as offline HTML in
  every download.

## Known limitations

- **Largely untested in real projects.** Most features have automated tests,
  but very few have been used for real work. Work on copies and keep backups.
- **Unsigned builds.** Windows SmartScreen and macOS Gatekeeper warn on the
  first launch; the installation guide explains the steps.
- **Platforms.** macOS builds are Apple silicon only; Linux builds are x86_64
  only and cannot play or record audio inside the studio yet.
- **Compilers are not bundled.** Build VibeMap2 and VibeMap3 from their
  submodules or point VibeStudio at your own builds, and at ZDBSP or ZokumBSP.
- **Languages.** 47 interface languages are registered, but none is translated
  yet, so the studio shows English.
- **Not built yet.** Graphical shader editing, a sprite animation editor, and
  agentic AI workflows.

Read [Project status](https://github.com/themuffinator/VibeStudio/blob/v0.1.0-alpha.1/docs/manual/status.md)
before you start, and report problems on
